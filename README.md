# RetireWise AI — Interactive Retirement Demo

**Live Demo for Financial Advisors**

A 9-step interactive retirement planning demo app built for financial advisors to use in client meetings. Shows a complete retirement picture — live, personalized, in the first 10 minutes.

## Features
- 3 pre-built client personas (Margaret Ellis, Sarah & Michael, David Chen)
- Live sliders — real-time projection updates
- AI Copilot with 6 personalized responses
- Portfolio optimizer with donut chart allocation
- Market crash stress test (2008, COVID, Dot-Com)
- Social Security optimizer with break-even analysis
- Personalized retirement roadmap (milestone timeline)
- Full plan summary with Retirement Confidence Score™
- Lead capture form → CRM enrollment

## Tech Stack
- Vanilla HTML/CSS/JS (zero dependencies except Chart.js CDN)
- Single file — fully self-contained
- Mobile responsive
